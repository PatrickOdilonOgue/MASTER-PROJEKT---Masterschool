# MASTER-PROJEKT---Masterschool
 Kundensegmentierung für TravelTide 🚀.

Beschreibung
Dieses Projekt simuliert eine reale Datenherausforderung in einem professionellen Umfeld, in dem das Ziel darin besteht, das Start-up-Unternehmen TravelTide dabei zu unterstützen, die Kundenbindung durch eine datenbasierte Marketingstrategie zu verbessern. Als Analyst/in habe ich die Aufgabe, Kunden in aussagekräftige Gruppen zu segmentieren und personalisierte Empfehlungen für ein innovatives Belohnungsprogramm zu geben.
Ziele
- Die Daten von TravelTide erforschen und bereinigen.
- Entwerfen Sie relevante Metriken durch Feature Engineering.
- Segmentierung von Kunden in signifikante Gruppen mithilfe von Clustering-Algorithmen.
- Präsentation der Ergebnisse in Form von Storytelling mit umsetzbaren strategischen Empfehlungen.
